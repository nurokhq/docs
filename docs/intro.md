# Nurok documentation

Guides and reference for building on Nurok. This site is the public home for
integration guides, concepts, and API reference.

## What's here

Nothing yet — this is the initial scaffold. Content arrives in follow-up changes.

## Contributing

The site is built with [Docusaurus](https://docusaurus.io) and lives in
[`nurokhq/docs`](https://github.com/nurokhq/docs). Pages are Markdown files under
`docs/`, and the sidebar is generated from the folder structure. Open a pull request —
every PR gets a build check, and merging to `main` publishes.

See the [README](https://github.com/nurokhq/docs#readme) for local setup.
